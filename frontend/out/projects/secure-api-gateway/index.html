Project

Kong-based API gateway with OAuth2, rate limiting, and compliance enforcement.

Challenge

Microservices architecture needed a centralized entry point with consistent security policies, authentication, and rate limiting across 50+ internal and external APIs.

Approach

Deployed Kong API Gateway in Kubernetes with custom Lua plugins for compliance checking, request transformation, and detailed audit logging. Integrated OAuth2 with Okta for unified authentication. Implemented request validation and data masking for sensitive fields.

Impact

Reduced security incidents by 60%. Centralized permission management across all services. Provided single enforcement point for rate limiting and authentication. Enabled developers to securely expose APIs without direct infrastructure access.

Details

Tools: Kong, Kubernetes, Lua, Python, PostgreSQL, Okta

Repository

Built for a local-first launch, then EC2, S3 storage, and a custom domain later.
